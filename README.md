# Bank Risk Register Assessment

## Overview

This project demonstrates a cybersecurity risk assessment conducted for a commercial banking environment. The assessment evaluates operational risks affecting the bank’s financial assets and prioritizes risks based on likelihood and severity scores.

The project focuses on identifying security threats, estimating potential impact, and calculating overall risk priority using a standard risk scoring methodology.

## Objective

- Identify cybersecurity risks
- Analyze operational risk factors
- Estimate likelihood scores
- Estimate severity scores
- Calculate overall risk priority
- Support risk-based security decisions

## Skills Demonstrated

- Risk assessment
- Risk scoring
- Threat analysis
- Risk prioritization
- Security governance
- Cybersecurity documentation

## Risk Formula

```text
Likelihood × Severity = Risk Priority
```
